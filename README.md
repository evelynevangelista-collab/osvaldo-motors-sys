O cliente do projeto é o Sr.Osvaldo da mecânica Osvaldo Motors.
O contratante solicitou um sistema que fosse comtemplado os principais requesitos solicitados:

O sistema deve possuir uma tela de cadastro e lançamento de Ordem de Serviço (OS), contendo nome do cliente, placa, modelo do veículo e descrição dos serviços feitos;

O sistema deve possuir uma funcionalidade para inclusão e cálculo de valor de peças utilizadas na OS.

Para veículos de marcas importadas o sistema deve aplicar automaticamente um acréscimo de 20% sobre o valor base da mão de obra.

O sistema deve ser de uso estritamente interno, sem qualquer tipo de acesso ou portal voltado ao cliente.

A interface gráfica do aplicativo mobile deve utilizar as cores Laranja e Preto, com o uso de botões amplos para uso direto e eficiente.

O sistema deve permitir o registro de entrada de notas fiscais de peças de fornecedores para acompanhamento de contas a pagar e a receber.
